# Local VTT v0.1.17

## Added

- Added scene map variants so a scene can keep multiple same-size map versions for floors, lighting changes, time-of-day swaps, and similar encounter variants ([#108](https://github.com/errorsallthethings/Local-VTT/pull/108)).
- Added a table message overlay for sending short GM-authored messages to the player-facing display ([#109](https://github.com/errorsallthethings/Local-VTT/pull/109)).
- Added weather preset packs and a refreshed Effects layer weather settings layout for managing active rain, snow, fog, and sand effects ([#110](https://github.com/errorsallthethings/Local-VTT/pull/110)).
- Added dice impact audio controls, tunable dice sound settings, and scene-roll throw direction options ([#111](https://github.com/errorsallthethings/Local-VTT/pull/111)).
- Added an Arrow Pointer table tool for click-drag-release directional callouts on the shared map ([#112](https://github.com/errorsallthethings/Local-VTT/pull/112)).

## Changed

- Improved weather rendering alignment on smaller maps and refined snow drift behavior at strong horizontal drift settings.
- Improved rain opacity handling so weather opacity affects the visible rain streak set more consistently.
- Updated Drawing and Template tool icons for clearer Tools menu and layer navigation.
- Refined expanded ping behavior by keeping sonar-style attention markers separate from the new arrow pointer workflow.

## Tests

- Ran the full local project check and Electron smoke coverage for the release branch after the 0.1.17 feature merges.
