# Local VTT v0.1.15

## Added

- Added configurable grid coordinates for map displays, including label placement and formatting controls ([#78](https://github.com/errorsallthethings/Local-VTT/issues/78))
- Saved Player View Display Profiles ([#39](https://github.com/errorsallthethings/Local-VTT/issues/39))
- Multi-Monitor Diagnostic Wizard ([#40](https://github.com/errorsallthethings/Local-VTT/issues/40))
- Added Player View test pattern support for display setup and table calibration ([#96](https://github.com/errorsallthethings/Local-VTT/pull/96))
- Added campaign maintenance tools for health checks, unreferenced asset pruning, thumbnail regeneration, and token asset optimization ([#101](https://github.com/errorsallthethings/Local-VTT/pull/101))

## Changed

- Completed the mid-release codebase audit hardening pass for architecture, persistence, asset handling, Player View behavior, documentation, and release readiness ([#101](https://github.com/errorsallthethings/Local-VTT/pull/101))
- Split large Electron main-process responsibilities into focused modules for campaign operations, asset import, thumbnail maintenance, Player View IPC, metadata backups, path safety, and packaging diagnostics ([#101](https://github.com/errorsallthethings/Local-VTT/pull/101))
- Split large renderer surfaces into smaller scene, layer panel, tools menu, workspace, dice, player-view, and campaign workflow modules ([#101](https://github.com/errorsallthethings/Local-VTT/pull/101))
- Improved token import behavior so finalized token art uses optimized campaign-owned thumbnails instead of retaining unnecessary oversized source files ([#101](https://github.com/errorsallthethings/Local-VTT/pull/101))
- Improved video map thumbnail handling with safer fallback behavior for formats Electron cannot decode directly ([#101](https://github.com/errorsallthethings/Local-VTT/pull/101))
- Improved Player View scene delivery, turn order visibility, player seat indicators, and display-state recovery after window open or reload ([#101](https://github.com/errorsallthethings/Local-VTT/pull/101))
- Added schema migration structure, persistence codecs, safer path handling, atomic metadata writes, and clearer user-facing error messages for local campaign files ([#101](https://github.com/errorsallthethings/Local-VTT/pull/101))
- Updated architecture, project structure, release process, canvas performance, and PlantUML documentation to reflect the current application boundaries ([#101](https://github.com/errorsallthethings/Local-VTT/pull/101))

## Fixed

- Fixed Player View visual smoke reliability by retrying scene delivery until the renderer confirms the scene canvas is ready ([#101](https://github.com/errorsallthethings/Local-VTT/pull/101))
- Fixed campaign health behavior around referenced and unreferenced map assets so maintenance results remain consistent after thumbnail regeneration and pruning ([#101](https://github.com/errorsallthethings/Local-VTT/pull/101))
- Fixed regressions around cropped token thumbnails and optimized token asset promotion for campaign-owned token art ([#101](https://github.com/errorsallthethings/Local-VTT/pull/101))

## Tests

- Added Electron visual smoke coverage for Player View scene rendering, overlays, display basics, and screenshots ([#58](https://github.com/errorsallthethings/Local-VTT/issues/58))
- Expanded unit coverage across Electron IPC, campaign persistence, asset import and pruning, metadata backups, thumbnails, Player View sync, display profiles, scene editing, drawing and template geometry, environment effects, dice, turn order, and release artifact validation ([#101](https://github.com/errorsallthethings/Local-VTT/pull/101))
- Added release metadata, documentation link, and package artifact validators to the standard release readiness checks ([#101](https://github.com/errorsallthethings/Local-VTT/pull/101))
